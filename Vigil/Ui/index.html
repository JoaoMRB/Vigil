      When the PC is locked

      Dim shows only the time, with the backlight low. Before the PC sleeps, the screen always turns off.

      Start with Windows Opens in the notification area when you sign in.
      CPU temperature Needs administrator rights. Windows asks once, then Vigil restarts.
      Approximate CPU temperature Without the driver, shows the motherboard's ACPI temperature instead, marked ~. It is often well below the CPU's own, so it is off unless you want it.
      Check for updates Once a day, asks GitHub whether there is a newer version. Nothing about you or this PC is sent.
      Diagnostics Copies the versions, the display's state, the settings and the end of the log, to paste into a bug report. No city, name or readings.
